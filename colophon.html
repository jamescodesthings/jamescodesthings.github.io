Colophon

How this site is made.

Stack

A small Node static site generator, with no framework and no bundler. It turns JSON data and Markdown posts into plain HTML, CSS and a little JavaScript.

  • Node runs the build
  • EJS page templates
  • markdown-it blog posts
  • Shiki code highlighting
  • sharp image processing
  • satori share card layout
  • @resvg/resvg-js share card PNGs
  • lightningcss CSS bundling and minifying

Fonts

Self-hosted Latin variable fonts, all under the SIL Open Font Licence.

  • Bricolage Grotesque headings
  • Figtree body text
  • Geist Mono code and labels

Hosting

Hosted on GitHub Pages and deployed by a GitHub Actions workflow (.github/workflows/deploy.yml) on every push to main. The source is public at github.com/jamescodesthings/jamescodesthings.github.io.
